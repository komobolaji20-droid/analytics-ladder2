🧭 Lesson 1: Getting to Know Excel

Let's start simple Excel is like a giant grid of boxes — like graph paper on your computer. Each box is called a cell, and every cell has an address, just like a house has an address on a street. The box in the first column and first row is called A1. The one next to it is B1. Simple!

Key Ideas

📍 Navigating Excel: Use the arrow keys or click any cell to move around. Rows are numbered (1, 2, 3…) and columns are lettered (A, B, C…).

🔗 Cell References — Relative vs. Absolute: When you write a formula and copy it to other cells, Excel normally shifts the reference automatically (this is called "relative" — like A1). Sometimes you want a cell to stay locked in place no matter where you copy the formula — you do this by adding dollar signs, like $A$1 (this is called "absolute").

🏷️ Named Ranges: Instead of remembering "the total is in cell D15," you can give that cell a name like TotalSales — so your formulas read like plain English: =TotalSales*0.1.

📋 Tables & Formatting: Turning a plain grid of data into an official "Table" (Insert → Table) makes Excel treat it smartly — automatic filtering, consistent formatting, and formulas that expand automatically when you add new rows.

A Simple Example You're tracking your pocket money. Cell B2 has "₦500" for Monday. If you write a formula in C2 that says =B2*2 and copy it down to C3, Excel automatically changes it to =B3*2 — that's a relative reference following you down the sheet.

🧠 Now You Try (Exercise) Open Excel (or Google Sheets). Type five days of the week down column A, and a made-up amount of money next to each in column B. In column C, write a formula that doubles the amount, then copy it down all 5 rows. Watch how the cell reference changes automatically.

✅ Big Idea to Remember Every skill in Excel builds on this one idea: cells have addresses, and formulas use those addresses to do the thinking for you.

➕ Lesson 2: Core Formulas & Lookup Functions

Let's start simple Formulas are how you tell Excel to calculate something instead of doing the maths yourself. Every formula starts with an equals sign (=).

Key Formulas to Know

  • =SUM(range) — adds up numbers
  • =SUMIFS(range, condition_range, condition) — adds up numbers, but only ones that match a condition (e.g., total sales, but only for "Lagos")
  • =COUNTIFS(...) — counts entries that match a condition
  • =AVERAGEIFS(...) — finds the average, but only for matching entries
  • =IF(condition, value_if_true, value_if_false) — makes a decision inside a cell
  • Nested IF: putting one IF inside another, for more than two possible outcomes (e.g., grading A/B/C/F)

Lookup Functions These help you find information from a big table. The modern favorite is =XLOOKUP(what_to_find, where_to_look, what_to_return). For example: =XLOOKUP("Bolaji", A:A, C:C) finds "Bolaji" in column A and returns the matching value in column C — like looking up someone's phone number using their name.

A Simple Example A shop has a list of products and prices. Instead of manually searching for "Rice" and typing its price, you write =XLOOKUP("Rice", A:A, B:B) and Excel finds it instantly — even in a list of 10,000 items.

🧠 Now You Try (Exercise) Make a small table: Name, Subject, Score (5 rows). Use =AVERAGEIFS to find the average score for just one subject. Then use =XLOOKUP to find one specific student's score by typing their name.

✅ Big Idea to Remember Formulas do the repetitive thinking so you don't have to. The moment you type numbers into a calculator by hand instead of using a formula, you've missed the whole point of Excel.

🧹 Lesson 3: Text Functions & Data Cleaning

Let's start simple Real-world data is almost never perfectly neat. Names might have extra spaces, text might be in the wrong case, or the same customer might accidentally appear twice. Before you can analyze data, you usually have to clean it first — just like washing vegetables before cooking.

Key Text Functions - =TRIM(text) — removes extra spaces - =LEFT(text, n) / =RIGHT(text, n) — grabs characters from the start or end of text - =MID(text, start, n) — grabs characters from the middle - =CONCATENATE(...) or =TEXTJOIN(...) — joins pieces of text together (e.g., joining "John" and "Doe" into "John Doe")

Data Cleaning Tools - Remove Duplicates (Data tab → Remove Duplicates): deletes repeated rows automatically - Handling blanks and errors: use =IFERROR(formula, "message") to replace scary error codes with something readable, like "Not Found"

A Simple Example A spreadsheet has " John Doe " with extra spaces at the start and end. =TRIM(A2) cleans it up to "John Doe" — which matters, because "John Doe" and " John Doe " look the same to a human but are treated as completely different text by Excel.

🧠 Now You Try (Exercise) Type your first and last name into two separate cells, with a few extra spaces added by accident. Use =TRIM and =TEXTJOIN (or =CONCATENATE) to combine them into one clean full name.

✅ Big Idea to Remember Messy data leads to wrong answers — even if every formula afterward is perfect. Cleaning always comes first.

✅ Lesson 4: Data Validation & Conditional Formatting

Let's start simple Have you ever filled a form online where you had to pick from a dropdown list instead of typing your own answer? That's data validation — it stops people from entering the wrong kind of information in the first place.

Data Validation Go to Data → Data Validation, and you can restrict a cell to only accept: a dropdown list of choices, numbers within a range, or dates within a range. This prevents typos like "Yess" instead of "Yes."

Conditional Formatting This automatically changes how a cell looks based on its value — for example, making any score below 50 turn red automatically, without you manually coloring each cell yourself.

A Simple Example You're building a form for your Ladder members to fill in their "Status" (Beginner, Intermediate, Advanced). Instead of letting people type anything, you create a dropdown list with just those 3 options — so nobody accidentally types "begginer" with a typo.

🧠 Now You Try (Exercise) List 10 random numbers in a column. Use Conditional Formatting to automatically highlight any number greater than 50 in green, and any number less than 20 in red.

✅ Big Idea to Remember Good spreadsheets prevent mistakes before they happen (validation) and make important information jump out visually (conditional formatting) — both save you from manually checking every single cell.

🔄 Lesson 5: Pivot Tables

Let's start simple Imagine you have 1,000 rows of sales data, and you want one quick answer: "What's the total sales per region?" Scrolling and adding manually would take forever. A Pivot Table does this in seconds — it's one of the most powerful tools in all of Excel.

How It Works You take your raw data and "pivot" it — dragging fields into four boxes: Rows, Columns, Values, and Filters. Excel automatically groups and summarizes everything for you.

A Simple Example You have a table of 500 sales records with columns: Region, Product, Amount. Drag "Region" into Rows and "Amount" into Values — instantly, you get a clean summary table showing total sales for each region, without writing a single formula.

🧠 Now You Try (Exercise) Create a small table with 10 rows: Name, Subject, Score. Build a Pivot Table that shows the average score per subject. Notice how fast it is compared to calculating it by hand.

✅ Big Idea to Remember Whenever you find yourself asking "what's the total/average/count of X, grouped by Y?" — that's a Pivot Table question. It's often faster than writing any formula.

🎨 Lesson 6: Charts & Data Visualization in Excel

Let's start simple Just like we learned in Part 1, a chart turns a boring list of numbers into a picture anyone can understand instantly. Excel makes this easy — highlight your data, click Insert, and pick a chart type.

Common Chart Types - Bar/Column Chart: comparing categories - Line Chart: showing change over time - Pie Chart: showing parts of a whole - Combo Chart: mixing two chart types together (e.g., bars for sales + a line for target) - Sparklines: tiny mini-charts that fit inside a single cell — great for showing a quick trend next to each row of data

A Simple Example You have monthly sales for the whole year in one row. Instead of a full chart, you insert a Sparkline right next to the numbers — a tiny line showing the trend at a glance, without taking up a whole chart's worth of space.

🧠 Now You Try (Exercise) Using the sleep-tracking data from Part 1 (or make up a new week of data), create a real Column Chart in Excel this time. Then try adding a Sparkline next to your data as well.

✅ Big Idea to Remember Charts aren't decoration — they're a translation tool. Always ask: "What chart type will make this number easiest for someone else to understand instantly?"

🔍 Lesson 7: Exploratory Data Analysis & Summary Statistics

Let's start simple Before you build any dashboard or draw any conclusion, you should first just explore your data — like walking around a new house before deciding where to put your furniture. This is called Exploratory Data Analysis, or EDA.

Key Ideas - Aggregated vs. Disaggregated Data: Aggregated means summarized (e.g., "Total sales: ₦2,000,000"). Disaggregated means broken down into detail (e.g., sales listed row-by-row per customer). You often need to move between both views. - Summary Statistics in Excel: use =AVERAGE(), =MEDIAN(), =MAX(), =MIN(), =COUNT() — or even faster, use the Data → Data Analysis → Descriptive Statistics tool to get all of them at once.

A Simple Example Before building any dashboard for a shop's sales, you first check: What's the average sale amount? What's the highest and lowest? Are there any obviously wrong numbers (like a sale of -₦500, which shouldn't exist)? This quick check often catches big problems early.

🧠 Now You Try (Exercise) Take any list of 10+ numbers (could be your family members' ages, or prices of things in your house). Find the average, max, min, and count using Excel formulas.

✅ Big Idea to Remember Never jump straight to charts and conclusions. Always explore your data first — you'll often catch mistakes or surprises before they become embarrassing later.

🔮 Lesson 8: What-If Analysis, Forecasting & Dynamic Arrays

Let's start simple What if you want to answer a "what if" question — like "What if I saved ₦500 every week — how much would I have in 6 months?" Excel has tools built exactly for these kinds of questions.

What-If Analysis & Goal Seek Goal Seek works backward: instead of you calculating the answer, you tell Excel the answer you want, and it figures out what input would get you there. Example: "I want my total savings to hit ₦50,000 — how much do I need to save weekly?"

Forecasting in Excel The FORECAST function (or the built-in Forecast Sheet tool) looks at your past data and predicts future values — useful for predicting next month's sales based on the last 12 months.

Dynamic Array Functions Modern Excel has smart functions that "spill" results automatically into multiple cells: - =UNIQUE(range) — lists only the unique values, removing repeats - =FILTER(range, condition) — pulls out only rows matching a condition - =SORT(range) — sorts a list automatically

A Simple Example You have a list of 100 customer orders, some regions repeated many times. =UNIQUE(A2:A100) instantly gives you a clean list of just the different regions — no manual checking needed.

🧠 Now You Try (Exercise) Make a list of 10 items with repeats (e.g., your favorite foods, with some listed twice). Use =UNIQUE to get a clean list with no repeats.

✅ Big Idea to Remember Excel isn't just for looking backward at what already happened — with What-If Analysis and Forecasting, it can help you plan forward too.

⚡ Lesson 9: Introduction to Power Query

Let's start simple Imagine you get sales data every week from 3 different sources — one messy Excel file, one CSV, and one from a website. Manually cleaning and combining these every single week would take hours. Power Query is Excel's built-in tool for automating exactly that.

Key Ideas - Power Query lets you connect to messy data, clean it step-by-step, and it remembers every step — so next week, when new data comes in, you just click "Refresh" and it repeats all the cleaning automatically - This is the beginning of something called ETL: Extract (get the data), Transform (clean and shape it), Load (bring it into your worksheet)

A Simple Example Every month, you download a messy sales report with extra spaces, inconsistent capitalization, and a few blank rows. You clean it once using Power Query. Next month, you get a new messy file — instead of cleaning it all over again by hand, you just click "Refresh," and Power Query repeats every step automatically.

🧠 Now You Try (Exercise) Open Power Query (Data tab → Get Data). Import any small CSV or Excel file you have and explore the interface. Try removing a column or changing a data type — notice how Power Query records each action as a numbered "step."

✅ Big Idea to Remember Power Query turns repetitive cleaning work into a one-time setup — this is your first real taste of automation, and it's exactly the same thinking you'll use later in Python.

⌨️ Lesson 10: Working Efficiently in Excel

Let's start simple The fastest Excel users you'll ever see barely touch their mouse. Learning a handful of keyboard shortcuts can save you hours over time — and it makes you look like a true professional.

Must-Know Shortcuts - Ctrl + C / Ctrl + V — copy / paste - Ctrl + Z — undo (your best friend!) - Ctrl + Arrow key — jump to the edge of your data instantly - Ctrl + Shift + L — turn filters on/off - Alt + = — auto-sum a column instantly - F4 — repeat your last action, or lock a cell reference ($) while typing a formula

A Simple Example Instead of scrolling down 500 rows to find the bottom of your data, press Ctrl + Down Arrow from the top of the column — Excel jumps you straight there in an instant.

🧠 Now You Try (Exercise) Open any spreadsheet with a few rows of data. Practice these 3 shortcuts: Ctrl + Down Arrow to jump to the bottom, Alt + = to auto-sum a column, and Ctrl + Z to undo something on purpose, just to see it work.

✅ Big Idea to Remember Speed isn't about typing fast — it's about not wasting time on repetitive clicks. A few shortcuts, practiced until they're automatic, will save you real hours every single week.
