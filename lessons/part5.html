🐍 Lesson 1: Python Fundamentals

Let's start simple Python is a programming language — a way of giving a computer clear, step-by-step instructions using text instead of clicking buttons. Unlike Excel or Power BI, there's no menu to click; you write exactly what you want, and Python does it.

Key Ideas - Variables: a labeled box for storing information, e.g., age = 25 - Data types: numbers (int, float), text (str), and True/False values (bool) - Operators: +, -, *, / for maths; ==, >, < for comparisons - Conditionals: if/elif/else — making decisions, just like Excel's IF - Loops: for and while — repeating an action automatically, without copy-pasting code - Functions: a reusable block of instructions you can call by name, instead of rewriting the same steps every time - Lists, Tuples, Dictionaries: different ways of storing groups of information together

A Simple Example

age = 15
if age >= 18:
    print("You can vote")
else:
    print("Not yet old enough to vote")

This checks the value stored in age, and prints a different message depending on the answer — exactly like an IF formula in Excel, but far more flexible.

🧠 Now You Try (Exercise) Write (on paper, or in a notebook if you have Python installed) a small piece of code using a for loop that prints the numbers 1 to 5, one per line.

✅ Big Idea to Remember Every single Python skill you'll ever learn is built from just a handful of core ideas: variables, conditions, loops, and functions. Master these, and everything else becomes easier to pick up.

📦 Lesson 2: Working with Data — NumPy & Pandas

Let's start simple Plain Python is great, but it wasn't built specifically for data. Two add-on libraries — NumPy and Pandas — turn Python into a serious data analysis tool, similar to how Power Query turns Excel into something much more powerful.

Key Ideas - Libraries: pre-written code you can "borrow" using import, instead of writing everything from scratch - NumPy: handles fast maths on lists of numbers, called "arrays" - Pandas: the single most important library for a data analyst — introduces the DataFrame, which is basically a spreadsheet living inside Python - Reading Data: Pandas can read CSV, Excel, SQL, and JSON files directly into a DataFrame with one line of code

A Simple Example

import pandas as pd

df = pd.read_csv("sales.csv")
print(df.head())

This reads an entire spreadsheet-like file into Python and shows you the first 5 rows — just like opening a file in Excel, but now you can control it entirely with code.

🧠 Now You Try (Exercise) If you have Python installed, try installing pandas (pip install pandas) and running the example above using any small CSV file you have. If not yet installed, write down what you think df.head() does, based on the explanation above.

✅ Big Idea to Remember A Pandas DataFrame is the Python equivalent of an Excel spreadsheet or a SQL table — almost everything you already know from Excel and SQL has a matching idea in Pandas.

🧼 Lesson 3: Data Cleaning & Preparation with Pandas

Let's start simple Just like in Excel and Power Query, real data almost always needs cleaning before you can trust it. Pandas has powerful, fast tools for doing this cleaning with just a few lines of code.

Key Ideas - df.info() and df.describe() — quick overviews of your data's structure and statistics - Handling missing values: df.dropna() (remove missing rows) or df.fillna(value) (fill them in) - Removing duplicates: df.drop_duplicates() - Data type conversion: making sure a "date" column is actually recognized as a date - Filtering and sorting: selecting only the rows you need, and arranging them - Handling outliers: spotting unusually extreme values that might be mistakes

A Simple Example

df = df.drop_duplicates()
df['amount'] = df['amount'].fillna(0)
df = df[df['amount'] > 0]

This removes duplicate rows, fills any missing amounts with 0, then keeps only rows where the amount is actually positive — three cleaning steps in three lines.

🧠 Now You Try (Exercise) In plain English, describe what would happen to your data if you ran df.dropna() instead of df.fillna(0) in the example above — how would the result be different?

✅ Big Idea to Remember "Garbage in, garbage out" applies just as much in Python as it did in Excel — always clean and inspect your data before analyzing it.

🔧 Lesson 4: Data Transformation

Let's start simple Once your data is clean, you'll often need to reshape it — select specific parts, create new columns, combine multiple tables, or summarize it by group. This is called data transformation.

Key Ideas - Selecting and Indexing: .loc[] (select by label) and .iloc[] (select by position) - Creating new columns: df['profit'] = df['revenue'] - df['cost'] - GroupBy and Aggregation: Pandas' version of SQL's GROUP BY - Merging/Joining: combining two DataFrames together, just like a SQL join - Pivot Tables in Pandas: yes, Pandas can build pivot tables too! - Applying functions: using .apply() with a custom function (often a lambda) to transform every row

A Simple Example

sales_by_region = df.groupby('region')['amount'].sum()
print(sales_by_region)

This is the Pandas equivalent of the SQL query SELECT region, SUM(amount) FROM sales GROUP BY region — same question, same answer, different tool.

🧠 Now You Try (Exercise) Write out (in plain English) how you'd use groupby to find the average score per subject, instead of the sum of sales per region.

✅ Big Idea to Remember By this point, notice a pattern: Excel Pivot Tables, SQL's GROUP BY, and Pandas' groupby() are really all doing the exact same job — summarizing data by category. Different tools, same underlying idea.

🔬 Lesson 5: Exploratory Data Analysis (EDA) in Python

Let's start simple Just like in Excel, before drawing conclusions, you explore your data first. Python makes this exploration fast and repeatable, especially for much larger datasets than Excel can comfortably handle.

Key Ideas - Descriptive statistics: df.describe() gives you count, mean, min, max, and more, for every numeric column at once - Correlation analysis: df.corr() — checks whether two numbers tend to move together (e.g., do more study hours relate to higher scores?) - Identifying patterns and trends: grouping and sorting to spot what stands out - Working with categorical data: df['column'].value_counts() — counts how often each category appears

A Simple Example

print(df['region'].value_counts())
print(df[['amount', 'quantity']].corr())

The first line shows how many sales came from each region. The second checks whether higher quantities tend to relate to higher amounts — both in two lines of code.

🧠 Now You Try (Exercise) If you had a dataset of students with "hours studied" and "exam score," what result would you expect from df[['hours_studied', 'score']].corr() — a strong positive relationship, no relationship, or a negative one? Why?

✅ Big Idea to Remember EDA in Python follows the exact same mindset as EDA in Excel — you're just doing it faster, and on much bigger datasets.

🎨 Lesson 6: Data Visualization in Python

Let's start simple Python has its own charting tools — and just like Excel's charts, they turn numbers into pictures. The two most popular libraries are Matplotlib (the foundation) and Seaborn (built on top of it, with prettier defaults).

Key Ideas - Matplotlib: the original, flexible charting library - Seaborn: makes attractive statistical charts with less code - Common chart types: bar, line, histogram, scatter, box plot — same concepts you learned in Excel and Part 1 - Customizing charts: titles, labels, colors, sizing - Plotly (overview): for interactive charts you can hover and zoom into, often used for dashboards

A Simple Example

import seaborn as sns
import matplotlib.pyplot as plt

sns.barplot(data=df, x='region', y='amount')
plt.title("Total Sales by Region")
plt.show()

Three lines of code, and you have a labeled bar chart — the same chart you might've built by clicking "Insert Chart" in Excel, but now fully controlled by code (and easy to repeat automatically).

🧠 Now You Try (Exercise) Looking at the code above, which part do you think controls what appears on the x-axis, and which part controls the y-axis?

✅ Big Idea to Remember Visualization principles don't change based on the tool — a bad chart is still a bad chart whether it's built in Excel, Power BI, or Python. The tool just changes how you build it.

📐 Lesson 7: Introduction to Statistics with Python

Let's start simple Remember statistics from Part 1 — averages, medians, and spread? Python lets you go a bit deeper, checking not just "what happened" but "is this difference actually meaningful, or just random chance?"

Key Ideas - Probability distributions (overview): patterns that describe how data tends to be spread out (e.g., the classic "bell curve") - Hypothesis testing (overview): a formal way of checking if a difference you observe (e.g., "Group A performed better than Group B") is likely real, or could just be random luck - SciPy: a Python library with ready-made statistical tests, so you don't have to build the maths from scratch

A Simple Example Imagine two groups of students used different study methods, and Group A scored higher on average. A hypothesis test (using SciPy) can tell you whether that difference is likely a real effect of the study method, or could easily have happened by chance with such a small group.

🧠 Now You Try (Exercise) Think of two groups you could compare in real life (e.g., two football teams' average goals, two classes' average test scores). Write down what question a hypothesis test could help answer about them.

✅ Big Idea to Remember Just because one number is bigger than another doesn't automatically mean the difference is "real" — statistics helps you tell the difference between an actual pattern and random noise.

🌐 Lesson 8: Working with Databases and APIs

Let's start simple So far we've mostly worked with files sitting on your computer. But real-world data often lives elsewhere — inside a company's database, or out on the internet through something called an API.

Key Ideas - Connecting Python to SQL databases: yes, you can run your Part 3 SQL knowledge directly from Python! - Running SQL queries from Python: using a library like sqlite3 or sqlalchemy - APIs: a way for one piece of software to request data from another over the internet (e.g., pulling live weather data) - The requests library: Python's tool for fetching data from an API - JSON: a common format APIs use to send data back — looks like nested dictionaries

A Simple Example

import requests

response = requests.get("https://api.example.com/weather")
data = response.json()
print(data['temperature'])

This fetches live data from a website's API and reads a specific value out of the response — a technique used constantly in real-world data analyst jobs.

🧠 Now You Try (Exercise) Think of one piece of live data you'd love to pull automatically (weather, football scores, currency exchange rates). Write down why an API would be more useful for this than manually checking a website every day.

✅ Big Idea to Remember A data analyst's skillset isn't limited to files someone hands you — SQL and APIs let you go get the data yourself, directly from its source.

⚙️ Lesson 9: Automating and Reporting

Let's start simple Remember how Power Query could "remember" your cleaning steps and repeat them automatically? Python can do the same thing — but with even more control, for tasks across your entire workflow.

Key Ideas - Writing reusable scripts: turning a series of manual steps into one script you can run anytime - Automating repetitive tasks: e.g., automatically cleaning and combining files every week - Exporting results: saving your cleaned data or charts to Excel, CSV, or PDF, ready to share

A Simple Example

df_clean = df.drop_duplicates().dropna()
df_clean.to_excel("cleaned_report.xlsx", index=False)

Two lines that clean your data and immediately save the result as a ready-to-share Excel file — a task that once took 20 minutes of manual clicking now runs in under a second.

🧠 Now You Try (Exercise) Think of a task you (or your Ladder members) do repeatedly by hand every week. Write down what the first step of "automating" that task with a script might look like.

✅ Big Idea to Remember The real power of Python isn't just analysis — it's turning any repeatable task into something that runs itself, freeing you to spend time on the thinking work instead of the clicking work.

🌟 Lesson 10: Version Control and Portfolio Readiness

Let's start simple We covered GitHub back in Part 1 — now let's apply it specifically to Python projects, since this is where most of your strongest portfolio pieces will come from.

Key Ideas - Using Git and GitHub with Python projects: saving and sharing your code, notebooks, and results - Structuring a project: a clear folder structure (e.g., a data/ folder, a notebooks/ folder, a README.md file) makes your project easy for anyone to understand - Publishing to GitHub: making sure your final project — code, explanation, and results — is visible and understandable to a stranger scrolling through your profile

A Simple Example A well-structured Python project on GitHub might look like:

sales-analysis-project/
├── data/
│   └── sales.csv
├── notebooks/
│   └── analysis.ipynb
├── README.md

The README explains, in plain language, what the project does, what question it answers, and what you found — exactly like the README lesson from Part 1, but now for a real, finished Python project.
